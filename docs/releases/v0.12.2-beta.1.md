# EraBridge v0.12.2-beta.1

发布说明草稿，尚未发布。公开前需完成[发行验收](https://github.com/UNI0NIUS/EU5ToVic3_EraBridge/blob/master/docs/RELEASING.md)，并用实际测试结果更新此说明。

EraBridge 将 Europa Universalis V 存档转换为 Victoria 3 候选模组，提供 Windows 桌面地图，用于检查转换结果、调整人口和耕地、编辑地区并导出模组。

## 本版内容

- 导入 EU5 文本、压缩和二进制存档，转换人口、文化、宗教、政治关系、经济、陆海军及开局战争。
- 在地图中查看国家、州和地块，调整人口、耕地、归属与州界，预览修改并撤销。
- 按源核心判断地块级释放范围，整州宣称独立按覆盖率判定；使用可解析的源旗帜。
- 首次使用可从本机游戏和自备 V3 开局存档生成转换规则。
- 附独立验收脚本，检查文件完整性、运行环境、转换、项目重开和导出回读。
- 修复旧宗教定义重复导致转换末段失败的问题。
- 增加统一开发文档入口，说明现行功能、模块架构、转换规则和验证范围。

## 适用范围与限制

主要开发与验证环境为 Windows x64、EU5 1.3.11 和 Victoria 3 1.13.11。其他版本、第三方模组及长期运行仍需验证。食物、就业和财政相关指标包含静态估算，不代表游戏运行后的价格、招聘和实际收支。

候选包包含规则配方，基准存档与游戏资源由使用者本机提供。Rakaly 依赖的授权范围、微软运行库分发依据、独立 Windows 验收及此候选的游戏内验证尚未完成，因此本草稿没有公开便携附件。
