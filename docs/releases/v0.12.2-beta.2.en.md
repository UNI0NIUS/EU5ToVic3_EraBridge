# EraBridge v0.12.2-beta.2 Windows community preview

[简体中文](v0.12.2-beta.2.md) · **English**

This version provides a runnable Windows x64 portable package for converting Europa Universalis V saves into candidate Victoria 3 mods. The workbench supports map inspection, population/arable-land adjustments, region editing, project saving and mod export.

## Download and first use

1. Download `EraBridge-0.12.2-beta.2-windows-x64.zip` from [this release](https://github.com/UNI0NIUS/EU5ToVic3_EraBridge/releases/tag/v0.12.2-beta.2) and extract the entire archive into a writable directory. Do not move the EXE alone. GitHub's automatic Source code ZIP/TAR files contain source only.
2. Run `EU5Converter.exe` and read/accept the bundled third-party component terms. Python and runtime dependencies are included; no separate development tools are required.
3. Choose “准备转换规则” (Prepare conversion rules), then select your own EU5 and Victoria 3 installations and a vanilla V3 1836.1.1 starting save. Games and saves are user-supplied. The beta.2 workbench predates the English interface added in beta.3.
4. Import an EU5 save, inspect the result and export the mod. Test it in a new Victoria 3 campaign.

Use `SHA256SUMS.txt` on the release page to verify the download. The package includes usage documentation, dependency licenses, a per-file manifest and `Test-PortableRelease.ps1` for independent acceptance checks. The software is unsigned; verify its source and hash before running it.

## Changes

- Add a Windows portable download, with importer and launcher rebuilt using Visual Studio Community 2022.
- Retain local initialization of game resources; games, player saves and complete generated mods are not distributed.
- Organize dependency notices and first-launch terms; include the Visual C++ runtime DLLs beside the importer.
- Retain beta.1 fixes for opening laws, religion colors, localization keys, repeated HRE logs and neutral-observer war participation.

## Known limitations

The primary validation environment was Windows x64, EU5 1.3.11 and Victoria 3 1.13.11. Other game versions, third-party mods and long campaigns were unverified. Resource-hash mismatches during initialization require updated rule recipes.

The first-week engine check of the 1337 sample still reported 60 resource-building capacity errors and 27 vanilla-script scope errors. The engine can reduce some resource buildings, and features such as dynamic state names can behave incorrectly. These counts belong to one sample, not every save. The release retains these known issues for community testing.

Development-machine checks covered rule initialization, original-save conversion, project save/reopen and export readback, with consistent data for 3,292 regions. Participants in five opening wars were also read back and checked. Independent Windows-machine acceptance remained pending. Food, employment and fiscal indicators include static estimates, not actual in-game prices, hiring or finances. See the [validation record](../PUBLICATION.en.md); the [original beta.2 record in Chinese](https://github.com/UNI0NIUS/EU5ToVic3_EraBridge/blob/v0.12.2-beta.2/docs/PUBLICATION.md) remains preserved at the tag.
