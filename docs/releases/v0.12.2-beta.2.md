# EraBridge v0.12.2-beta.2 Windows 社区测试版

**简体中文** · [English](v0.12.2-beta.2.en.md)

本版提供可直接运行的 Windows x64 便携包，将 Europa Universalis V 存档转换为 Victoria 3 候选模组。工作台支持地图检查、人口与耕地调整、地区编辑、项目保存和模组导出。

## 下载与首次使用

1. 下载附件 `EraBridge-0.12.2-beta.2-windows-x64.zip`，完整解压到可写目录。不要单独移动 EXE。GitHub 自动生成的 Source code ZIP/TAR 仅是源码。
2. 双击 `EU5Converter.exe`，阅读并接受包内第三方组件条款。已附 Python 和运行依赖，无需另装开发工具。
3. 点击“准备转换规则”，选择自己的 EU5、Victoria 3 游戏安装目录，以及 V3 原版 1836.1.1 开局存档。游戏与存档需要自行提供。
4. 导入 EU5 存档，检查转换结果并导出模组。在 Victoria 3 中新开战役测试。

同页的 `SHA256SUMS.txt` 用于核对下载。包内附使用文档、依赖许可、逐文件清单和 `Test-PortableRelease.ps1` 独立验收工具。软件没有数字签名；核对来源和摘要后再运行。

## 本版变化

- 增加 Windows 便携下载，使用 Visual Studio Community 2022 重建导入器与启动器。
- 保留游戏资源的本机初始化流程，发行包不含游戏、玩家存档或预生成完整模组。
- 整理依赖通知和首次启动条款，补齐导入器旁的 Visual C++ 运行 DLL。
- 延续 beta.1 的开局法律、宗教颜色、本地化键、HRE 重复日志及中立观察国战争判定修复。

## 已知限制

主要验证环境为 Windows x64、EU5 1.3.11、Victoria 3 1.13.11。其他游戏版本、第三方模组和长期战役尚未验证；初始化遇到资源摘要不符时，需要适配规则配方。

1337 样本的首周引擎检查仍发现 60 条资源建筑容量报错，以及 27 条原版脚本作用域报错。部分资源建筑会被引擎削减，动态州名等内容可能异常。这些数量来自特定样本，不代表所有存档；本版保留这些已知问题供社区继续测试。

已有开发机全流程检查覆盖规则初始化、原始存档转换、项目保存重开和导出回读，3292 个地区数据一致；开局 5 场战争成员也已回读核对。独立 Windows 机器尚未验收。食物、就业与财政指标包含静态估算，不代表游戏中的实际价格、招聘和收支。详细范围见[验证记录](https://github.com/UNI0NIUS/EU5ToVic3_EraBridge/blob/v0.12.2-beta.2/docs/PUBLICATION.md)。
