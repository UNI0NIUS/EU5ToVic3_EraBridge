# EraBridge v0.12.2-beta.3 — 中英文工作台 / Bilingual workbench

Windows x64 社区预发布版。下载 `EraBridge-0.12.2-beta.3-windows-x64.zip`，完整解压后运行 `EU5Converter.exe`；用 `SHA256SUMS.txt` 核对下载。首次启动阅读并接受第三方组件条款。GitHub 的 Source code 附件不是可直接运行的程序。

Windows x64 community pre-release. Download `EraBridge-0.12.2-beta.3-windows-x64.zip`, verify it with `SHA256SUMS.txt`, extract the complete folder and run `EU5Converter.exe`. Read and accept the bundled third-party terms on first launch. GitHub's automatic Source code archives are not runnable packages.

## 本次更新 / Changes

- 工作台即时切换简体中文和 English，保留语言偏好、地图选区及未应用参数；补充英文提示、计算依据、编辑校验和较长英文标签的布局。
- 导入、导出独立选择游戏显示语言，校验本地化键、语言头和 UTF-8 BOM，生成所选语言的安装说明。中英文资源均保留在输出模组中。
- 修复英文食物补建选项误用就业目标的问题；首次启动提示和组件条款提供双语文本。
- 新增英文 README、工作台与构建文档、问题模板和双语工坊发布材料。
- Switch the workbench between Simplified Chinese and English while retaining preferences, map selection and unapplied settings. English messages cover calculations and edit validation, with room for longer labels.
- Choose the game display language separately when importing or exporting. Localization keys, language headers and UTF-8 BOMs are checked, and installation guidance follows the chosen language. Both language resources remain in the mod.
- Fix English food construction choosing the employment goal. First-launch prompts and component terms are bilingual.
- Add English README, workbench/build guides, issue template and bilingual Workshop publishing materials.

在 Victoria 3 中选择与导出设置相同的语言，启用模组并开始新战役，再由游戏保存为 `.v3`。转换器生成开局世界模组，不直接写入 `.v3` 存档。自定义名称和原始日志不自动翻译。

Set Victoria 3 to the matching language, enable the exported mod and start a new campaign; the game creates the `.v3` file when you save. The converter produces a starting-world mod. Custom names and original logs are not automatically translated.

## 验证与限制 / Validation and limitations

- 隔离发行源码通过 133 项 Python 测试：工作台及语言相关 116 项、初始化 6 项、打包 8 项、发行完整性 3 项。
- 最终 ZIP 在带中文和空格的独立目录中解压，以随包 Python 检查全部清单摘要、依赖隔离、Tk 初始化窗口及中英切换。
- 启动器从本版源码重建；C++ 导入器源码未变，沿用 beta.2 已发布且摘要核对的原生二进制。未纳入其他未完成的转换规则或首都计算器改动。
- 133 Python tests pass against the isolated release source: 116 workbench/language tests, 6 initialization tests, 8 packaging tests and 3 release-integrity tests.
- The final ZIP is extracted into a separate path containing Chinese characters and spaces. Its bundled Python checks all manifest hashes, isolated dependencies, the Tk initialization dialog and Chinese/English switching.
- The launcher is rebuilt from this release's source. Unchanged C++ importer sources use the hash-verified beta.2 native binary. Unfinished conversion-rule and capital-calculator work is excluded.

上述便携检查在开发机执行，不能视为独立 Windows 或游戏内验收。本次未重新执行完整存档转换。英文游戏内显示、独立 Windows 环境和长期战役仍待验证；beta.2 已披露的资源建筑容量及部分原版脚本报错仍适用。底层日志、旧报告和旧浏览器工作台仍可能含中文。主要验证版本为 EU5 1.3.11 与 Victoria 3 1.13.11。

Portable checks ran on the developer machine, not an independent Windows installation or inside the game. A full save conversion was not repeated for this update. English in-game display, independent Windows environments and long campaigns remain unverified. Previously disclosed resource-building capacity and vanilla script errors still apply. Backend logs, historical reports and the legacy browser workbench may contain Chinese. The primary game versions are EU5 1.3.11 and Victoria 3 1.13.11.

游戏、玩家存档、完整规则和已接受条款记录不随包分发。首次使用从自己的两款游戏安装及 V3 原版 1836.1.1 开局存档准备规则。详细说明见 [中文工作台文档](../CONVERTER_WORKBENCH.md)、[English workbench guide](../CONVERTER_WORKBENCH.en.md) 和 [language coverage](../LOCALIZATION.en.md)。

Games, player saves, complete local rules and accepted-terms receipts are not distributed. Prepare rules from your own game installations and a vanilla V3 1836.1.1 starting save.
