# EraBridge v0.12.2-beta.3 — 中英文工作台

**简体中文** · [English](v0.12.2-beta.3.en.md)

Windows x64 社区预发布版。下载 `EraBridge-0.12.2-beta.3-windows-x64.zip`，完整解压后运行 `EU5Converter.exe`；用 `SHA256SUMS.txt` 核对下载。首次启动阅读并接受第三方组件条款。GitHub 的 Source code 附件不是可直接运行的程序。

## 本次更新

- 工作台即时切换简体中文和 English，保留语言偏好、地图选区及未应用参数；补充英文提示、计算依据、编辑校验和较长英文标签的布局。
- 导入、导出独立选择游戏显示语言，校验本地化键、语言头和 UTF-8 BOM，生成所选语言的安装说明。中英文资源均保留在输出模组中。
- 修复英文食物补建选项误用就业目标的问题；首次启动提示和组件条款提供双语文本。
- 新增英文 README、工作台与构建文档、问题模板和双语工坊发布材料。

在 Victoria 3 中选择与导出设置相同的语言，启用模组并开始新战役，再由游戏保存为 `.v3`。转换器生成开局世界模组，不直接写入 `.v3` 存档。自定义名称和原始日志不自动翻译。

## 验证与限制

- 隔离发行源码通过 133 项 Python 测试：工作台及语言相关 116 项、初始化 6 项、打包 8 项、发行完整性 3 项。
- 最终 ZIP 在带中文和空格的独立目录中解压，以随包 Python 检查全部清单摘要、依赖隔离、Tk 初始化窗口及中英切换。
- 启动器从本版源码重建；C++ 导入器源码未变，沿用 beta.2 已发布且摘要核对的原生二进制。未纳入其他未完成的转换规则或首都计算器改动。

上述便携检查在开发机执行，不能视为独立 Windows 或游戏内验收。发布前未重复执行完整存档转换，发布后复核见下文。英文游戏内显示、独立 Windows 环境和长期战役仍待验证；beta.2 已披露的资源建筑容量及部分原版脚本报错仍适用。底层日志、旧报告和旧浏览器工作台仍可能含中文。主要验证版本为 EU5 1.3.11 与 Victoria 3 1.13.11。

游戏、玩家存档、完整规则和已接受条款记录不随包分发。首次使用从自己的两款游戏安装及 V3 原版 1836.1.1 开局存档准备规则。详细说明见 [中文工作台文档](../CONVERTER_WORKBENCH.md)和[多语言支持](../LOCALIZATION.md)。

## 发布后复核（2026-10-04）

从 GitHub 重新下载的 ZIP 与校验文件一致，2,653 个清单文件全部通过摘要核验。在开发机上使用该下载版，从原版 1337.4.1 CHI（元）存档完成全新规则初始化、完整转换、项目保存重开与中英文导出回读：3,292 个地区、40,717 个地块、394,557,661 人口、4,191 级建筑一致；每种语言检查 22,748 个本地化键。两份模组的 1,056 个文件一致，仅元数据中的独立模组 ID 因导出目录不同而不同。原始存档未改动。

随机抽取的 1338 KNI 二进制存档在原生导入阶段报 `Unknown EU5 binary tokens: import refused`，尚未通过。该复核未进入游戏，也不能证明任意二进制存档均可转换。详见[验证记录](../PUBLICATION.md)和[问题与存档提交指南](../SUPPORT.md)。

本文在发布后补充双语说明与复核记录；原发布标签、ZIP 和 `SHA256SUMS.txt` 保持原样。
