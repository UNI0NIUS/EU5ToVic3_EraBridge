# EraBridge v0.12.2-beta.1 source preview

[简体中文](v0.12.2-beta.1.md) · **English**

This historical preview is for local builds and community testing. Its Source code ZIP/TAR downloads contain source only and cannot be run directly. This version has no Windows portable asset.

EraBridge converts Europa Universalis V saves into candidate Victoria 3 mods. Its Windows desktop map supports inspection, population/arable-land adjustments, region editing and mod export.

## Included in this version

- Import text, compressed and binary EU5 saves; convert population, cultures, religions, political relations, economies, armies, navies and opening wars.
- Inspect countries, states and provinces on a map; edit population, arable land, ownership and state borders with previews and undo.
- Determine province-level releasable territory from source cores; assess whole-state claims separately by coverage; use source flags where parseable.
- Prepare conversion rules from local games and a user-supplied V3 starting save on first use.
- Run a separate acceptance script for integrity, runtime, conversion, project reopening and export readback.
- Fix duplicate old religion definitions, ineffective opening laws, religion-color precision, localization-key conflicts and repeated HRE log messages.
- Fix neutral observers being counted as war participants and preventing opening wars from being created.
- Provide a unified documentation entry point covering features, architecture, conversion rules and validation scope.

## Scope and limitations

The main development/validation environment was Windows x64, EU5 1.3.11 and Victoria 3 1.13.11. Other versions, third-party mods and long campaigns required further testing. Food, employment and fiscal indicators include static estimates, not actual in-game prices, hiring or finances.

Source includes rule recipes; users supply baseline saves and game resources locally. At the time of beta.1, the scope of the Rakaly license and Microsoft's runtime redistribution basis still needed confirmation, so no precompiled runtime was distributed. This describes beta.1's release decision, not the packaging status of later versions. Independent Windows, third-party mod and long-campaign testing remained pending.

The development machine completed rule initialization, conversion of an original 1337 save, project save/reopen and export readback, with consistent data for 3,292 regions. This does not establish support for independent machines or arbitrary saves. Rerunning final stages on that conversion allowed first-week engine inspection and readback of the participants in five opening wars. Resource-building capacity and some vanilla-script errors remained unresolved. Community reproductions are welcome; long-campaign stability is not guaranteed.
