The first-launch [third-party component terms](../licenses/END_USER_TERMS.txt) contain the complete Chinese text followed by the complete English text. Original third-party licenses, upstream contribution policies and historical reference material retain their original text; bilingual project explanations do not replace them.

Documentation on `master` continues to evolve; fixed release tags and existing ZIPs retain their original snapshots. Tests and limitations in historical release notes belong to that version, with later reviews dated separately. Development conversations, personal installation records, progress notes and raw test data remain local rather than becoming public documentation.

Documentation follows [Humanizer-zh](https://github.com/op7418/Humanizer-zh) as an editorial reference: state technical facts directly, remove repetition and empty claims, and retain commands, values, qualifications and sources. Static checks, in-game validation and long campaigns cannot substitute for one another.
