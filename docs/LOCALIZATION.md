# 工作台与游戏语言

**简体中文** · [English](LOCALIZATION.en.md) · [文档索引](README.md)

从 `v0.12.2-beta.3` 起，发行包支持简体中文和英文工作台，以及独立的输出语言选择。

## 工作台语言

在主窗口“语言 / Language”中选择语言，即时更新界面。偏好保存在工作目录的 `desktop.json` 中，与 `last_project` 共存。切换保留未应用的参数、地图图层、筛选条件、选中地区与合并范围；后台任务、地图加载或定位未完成时，先等待任务结束再切换。

菜单、参数、地图图例、编辑对话框和工作台自身提示已有英文文本。州、国家、市场、战略地区和建筑名称优先使用所选语言的游戏及候选模组资源；模组覆盖原版，`replace` 覆盖普通目录。中文显示缺少条目时可回退英文。自定义名称保持原样，缺少名称时保留现有名称或脚本键。

计算依据、市场关系、耕地建议、补建与编辑校验已补充英文；首次启动与组件条款提供双语文本。较长英文标签和表头按可用宽度换行或扩展，食物与就业补建使用独立的内部选项值，不按译文前缀判断。

原始日志和保存的报告继续保留源语言；未接入翻译的底层诊断以及历史报告中的动态句子仍可能为中文。旧浏览器工作台 `converter_app.py` 尚未迁移。

## 生成对应语言的游戏结果

1. 导入 EU5 存档时，在“游戏显示语言”选择简体中文或 English。首次默认跟随工作台语言，之后导入对话框记住上次选择。
2. 转换继续生成中英文资源，并检查所选语言是否覆盖模组本地化键和动态国家名引用。缺少条目、错误语言头或缺少 UTF-8 BOM 会中止完成流程，避免把缺字结果当作成功包。
3. 导出编辑后的世界时可再次独立选择游戏显示语言；项目以 `output_language` 保存选择并递增修订号。旧项目没有该字段时仍可打开。
4. 输出 `README.txt` 使用所选语言，`package_report.json` 记录选择，`localization_verification.json` 记录键数量与检查范围。包内保留中英文目录，不会因为选英文而删除中文。
5. 在 Victoria 3 中选择相同游戏语言，启用输出模组并新开战役，再由游戏保存为 `.v3`。

转换器输出的是开局世界模组，不直接生成 `.v3` 存档，也不自动修改 V3 的语言设置。游戏显示语言由 V3 自己决定。语言选择不会改变人口、归属、外交、文化标识、宗教标识或转换规则。自定义国名、人名、模组名称不作机器翻译。

检查确认键存在和文件格式，不判断译名质量，也不代表已完成游戏内测试。空姓氏、空事件风味段落可能是合法文本，因此空字符串不作为缺键处理。

## 维护和扩展

工作台资源位于 `tools/converter_locales/en.json`，中文源消息为默认回退；加载、参数占位符检查和游戏名称解析在 `tools/converter_i18n.py`。新增界面文案通过实例的 `self.tr(...)` 调用；不要翻译 TAG、路径、JSON 字段或操作类型。完整句子使用编号占位符，译文可以调换顺序但须保留占位符集合。

新增语言须更新 `LANGUAGES` 注册表、语言码规范化函数、界面 JSON 词典，以及 `converter_output_language.py` 中的输出语言与安装说明。游戏内容的生成器目前明确生成 `english` 和 `simp_chinese`；支持第三种游戏语言还须扩展国家名、动态身份、事件、文化、宗教及相关资源生成器，不能只复制英文文件并修改语言头。

后端界面提示用 `Message(中文模板, 参数...)` 保留可翻译模板，界面用 `self.tr(...)` 渲染。它仍是原文字符串，JSON 报告与日志保持原格式；不要对拼接后的用户文本做查找替换。工作进程通过可选的 `error_message` 字段传递模板，原有 `error` 字段保留原文；旧状态文件仍可读取。

发布打包和本地代码刷新都必须包含 `converter_locales`。运行针对性检查：

```powershell
python -X utf8 -m unittest discover -s tools -p test_converter_i18n.py
python -X utf8 -m unittest discover -s tools -p test_converter_desktop.py
python -X utf8 -m unittest discover -s tools -p test_converter_workbench.py
python -X utf8 -m unittest discover -s tools -p test_prepare_release.py
```
