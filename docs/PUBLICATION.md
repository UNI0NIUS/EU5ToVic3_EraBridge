# 公开材料与验证范围（0.12.2）

`v0.12.2-beta.2` 提供源码与 Windows x64 便携包，供社区测试。此前 `beta.1` 仅提供源码，保持原有标签。

## 包含的材料

- 上游 Git 历史、原版权声明、许可证和子模块引用。
- C++ 存档导入改动、Python 转换与工作台工具及测试。
- 转换配置、映射与研究依据。
- EraBridge 图标、启动入口和必要的使用、构建文档。

公开文档仅包含面向读者的使用说明、技术规则、架构、构建和发布材料，见[文档索引](README.md)。开发对话、个人安装记录与阶段日志不随源码发布。`config/personal/` 中部分配置绑定旧战役，使用时需核对字段范围。

## 排除的材料

游戏安装文件、玩家存档、基准存档、生成的完整规则包、游戏提取素材、候选模组、项目编辑记录、日志、缓存和编译工具链均不上传。便携 ZIP 只作为 Release 附件提供，不提交到源码仓库。个人安装脚本也保留在本地。

## 验证范围

2026-10-03 在当前 Windows 开发环境运行 `tools/Build-Personal.ps1`，C++ 构建及 CTest 通过（27 个套件、121 项测试）；首次初始化和验收工具加入后，Python 3.13.9 环境中 530 项测试全部通过。依赖版本为 NumPy 2.3.1、Pillow 12.0.0。

候选运行环境在带中文和空格的独立路径下完成检查：清除外部 Python 配置、将 PATH 限于 Windows 系统目录后，NumPy 运算、Pillow 图像读写、Rakaly 加载及 Tk 工作台创建与关闭通过，默认游戏和候选路径为空。这是开发机上的移目录检查，尚未进行无开发环境机器的完整验收。

候选 `66a99fe` 已使用包内 Python，从自备游戏、V3 原版开局及原始 1337 存档完成一次全新验收：规则初始化、完整转换、静态校验、人口回读、项目保存重开和导出回读均通过，3292 个地区数据一致。此次未复用旧转换的中间目录。该结果来自现有 Windows 开发机，独立机器验收仍待执行。

在同一全新转换结果上重跑最终生成与校验阶段后，V3 1.13.11 已实际推进至 1836.1.7，并读取开局与首周存档。开局 5 场战争的双方成员与源记录一致；法律保留、宗教颜色格式、本地化键冲突和 HRE 重复日志问题已修复。首周出现后续参战者，不将其当作开局映射结果。

游戏内验收尚未整体通过：引擎仍会削减部分超出实际资源容量的建筑，原版动态州名等脚本也存在无效作用域或缺失文本报错。资源容量计算需与引擎回读对齐；不能以单元测试或顺利推进首周代替这些检查。此次复核复用了此前全新转换的经济中间结果，未将其表述为修复后重新执行所有转换阶段。

1337、1780、1787 样本另有历史转换或分项检查记录，但尚不足以证明干净克隆、任意存档或游戏内长期运行均通过。便携包随附依赖许可与通知；已披露的兼容性限制留待社区测试。

## 文档与 Release 材料

使用说明按软件行为组织，技术文档保留规则、条件和验证边界。历史调试数据不作为现版本验收结果，上游许可证与第三方原文保持不变。

`v0.12.2-beta.2` 使用 Visual Studio Community 2022 17.14 的 C++ 工具链和 Windows SDK 10.0.26100.0 重建导入器、启动器，C++ 测试和 532 项 Python 测试通过；发行清单增加来源提交后，8 项打包测试另行通过。Windows 包附正式 Visual C++ 运行库、Python 及其依赖；首次启动需接受第三方组件条款。独立验收工具仍明确标记 `clean_machine_verified: false`，不会将开发机检查视作独立环境认证。

beta.2 便携运行环境另在中文和空格路径下，从原始 1337 存档完成全新规则初始化、原生导入、完整转换、项目保存重开及导出回读，3292 个地区数据一致。使用包内 Python 3.13.9、NumPy 2.3.1、Pillow 12.0.0 和 Tk 8.6，外部 Python 配置已清除。该检查在 Windows 开发机完成；本轮没有重新进行游戏内首周或长期战役测试。

准备脚本生成独立目录、逐文件清单、SHA-256 和来源报告。完整流程见[发布准备](RELEASING.md)，下载和限制见[发行说明](releases/v0.12.2-beta.2.md)。
