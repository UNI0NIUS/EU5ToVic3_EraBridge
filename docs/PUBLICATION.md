# 源码与验证范围（0.12.2）

仓库提供源码、配置、测试和技术文档，供构建与开发。尚未发布可直接运行的 Windows 安装包。

## 包含的材料

- 上游 Git 历史、原版权声明、许可证和子模块引用。
- C++ 存档导入改动、Python 转换与工作台工具及测试。
- 转换配置、映射与研究依据。
- EraBridge 图标、启动入口和必要的使用、构建文档。

公开文档仅包含面向读者的使用说明、技术规则、架构、构建和发布材料，见[文档索引](README.md)。开发对话、个人安装记录与阶段日志不随源码发布。`config/personal/` 中部分配置绑定旧战役，使用时需核对字段范围。

## 排除的材料

游戏安装文件、玩家存档、基准存档、生成的完整规则包、游戏提取素材、候选模组、项目编辑记录、日志、缓存、编译工具链和现有 ZIP 均不上传。个人安装脚本也保留在本地。

## 验证范围

2026-10-03 在当前 Windows 开发环境运行 `tools/Build-Personal.ps1`，C++ 构建及 CTest 通过（27 个套件、121 项测试）；首次初始化和验收工具加入后，Python 3.13.9 环境中 528 项测试全部通过。依赖版本为 NumPy 2.3.1、Pillow 12.0.0。

候选运行环境在带中文和空格的独立路径下完成检查：清除外部 Python 配置、将 PATH 限于 Windows 系统目录后，NumPy 运算、Pillow 图像读写、Rakaly 加载及 Tk 工作台创建与关闭通过，默认游戏和候选路径为空。这是开发机上的移目录检查，尚未进行无开发环境机器的完整验收。

本次使用包内 Python 从自备游戏和基准生成规则，再执行 1337 样本转换。检查中修复重复宗教定义，保留已完成阶段并重跑末段后，静态校验和人口回读通过；项目保存重开及导出后 3292 个地区数据一致。这包含修复后的末段重跑，尚未替代最终候选在独立机器上的完整重跑。

1337、1780、1787 样本另有历史转换或分项检查记录，但尚不足以证明干净克隆、任意存档或游戏内长期运行均通过。公开二进制仍需要完成独立的资产许可、依赖通知和可移植性核查。
