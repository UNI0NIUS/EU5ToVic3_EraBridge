# 源核心、宣称与释放边界（0.12.2）

**简体中文** · [English](CONVERTER_SOURCE_CORES.en.md)

[文档索引](README.md) · [发布准备](RELEASING.md)

源核心用于判断可释放地块，整州宣称另按覆盖率判断。可释放国家的旗帜优先从源定义恢复。

## 边界规则

1. 仅使用源存档当前 `cores`，不读取已经失效的历史授予或把文化本土等同于国家核心。
2. 一个 V3 地块对应多个 EU5 地点时，至少一半映射地点具有该国核心，才把它列为该国可释放地块。地点去重；这是离散映射支持率，不是像素面积、人口占比或历史主权结论。
3. 整州宣称要求合格核心地块数 / 全州已分配陆地地块数 **≥ 30%**。分母包括其他国家占有的州内地块；不能只用本国占有部分。未映射但已分配的地块也计入分母。
4. 释放使用原生 `provinces` 清单，不使用 `states` 或 `use_culture_states`。不足 30% 的小国仍能按合格核心地块释放；获得整州宣称也不会增加其可释放地块。
5. 玩家移动地块或调整州界后，导出时重新计算各州覆盖率和休眠国家首都，核心地块本身不因合并转给征服者。

30% 是保守程度适中的游戏参数，不是已被史学证明的界线。1787 测试样本中的阈值对比：

| 判定 | 源核心州宣称数 |
| --- | ---: |
| 旧版：任意相交 | 3472 |
| 地块支持率过滤后，州门槛 20% | 1258 |
| 地块支持率过滤后，州门槛 30% | 996 |
| 地块支持率过滤后，州门槛 40% | 800 |
| 地块支持率过滤后，州门槛 50% | 677 |

例如旧版曾因 1 个地块而给予包含 1028 个地块的阿拉斯加整州宣称。州门槛用于排除此类微小边角；更高门槛会进一步压缩跨州边缘宣称。另有 99 条由原有独立地区规则产生的宣称，单独记账并保留；上述表格只统计源核心派生宣称。

## 释放粒度的依据

V3 1.13.11 原版文件 `game/common/country_creation/00_releasable_countries.txt` 中，JAN、NAS、ALT 等均以 `provinces = { ... }` 定义释放领土。NAS 原生条目直接列出三个地块，并不要求整州。实现沿用这个已存在的引擎接口，而非先放出整州后再返还土地。

[Paradox 官方模组开发日志](https://www.paradoxinteractive.com/games/victoria-3/news/victoria-3-dev-diary-60-modding)说明州由地块组成、同一州区域可以由多个国家分别拥有；具体释放语法以对应版本的游戏文件为准。

## 国旗

休眠国家现在也使用 `FlagExporter`，按源国家旗帜列表及可判定条件恢复图案、纹章、纹理与命名颜色。复用原版 TAG 时覆盖其原有旗帜列表，防止显示另一个国家的原版旗；被释放为属国时默认保留完整源旗。

同一 1787 测试样本的 750 个休眠可释放国家中，596 个恢复了 EU5 脚本旗。其余 154 个没有可恢复的源旗定义，使用有明确审计标记的程序生成备用旗，不能称为历史原旗。源存档 `coat_of_arms_manager` 为空（`next_id=0`），没有额外保存的动态纹章可用于补齐。

报告 `source_claims.json` 包含每个国家的核心地块、逐州覆盖率、保留宣称、旗帜来源和失败原因。旧项目升级在独立目录完成，不重跑经济补建；旧人口、建筑、开局所有权和已保存编辑均保留。游戏存档中的既有宣称不会由修改开局文件追溯删除，边界修复需新开局验证。
