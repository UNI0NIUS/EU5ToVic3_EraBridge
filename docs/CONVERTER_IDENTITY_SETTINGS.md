# 通用转换器的文化与宗教设置

**简体中文** · [English](CONVERTER_IDENTITY_SETTINGS.en.md)

[文档索引](README.md) · [发布准备](RELEASING.md)

适用于桌面版 0.12.2。转换按源文化键、源居民分布和明确配置判断身份，不复用旧战役的国家或人口历史。规则更新用于后续转换，已有候选包需通过项目升级流程更新。

## 规则与适用范围

- `culture_mapping.json` 按源文化键映射；保留通用版已有的跨存档审查，再应用 `m5_culture_identity_corrections.json` 和 `m5_culture_framework.json` 的明确修正。不会用旧战役的居民分布反推新存档文化。
- `assets/` 仅含文化、宗教、传承、语言、文化圈定义、身份本地化和宗教图标。定义按键合并，最新明确修正优先；不携带国家、人口、经济、领土历史或旧 TAG 的国名。
- `identity_homelands.json` 合并历史核心及经确认的身份规则；普通文化需要当前源居民锚点与核准核心州相交。原版本土保留，未决项目不按人口比例自动补齐。
- 移民文化继续按来源及殖民地区生成，宗教保持原居民宗教。本土必须严格超过**全州**人口 50%，不是某国拥有部分的多数。普通文化不使用该多数补充规则。
- 卢伊设计明确面向 1830 年代以前。通用配置从 1830 年起保留原有跨存档审查的 Lozi 身份，不将前科洛洛语言设定无条件套入更晚存档。这是保守适用界线，不是模拟语言变化发生的确切年份。
- 审核状态保留在配置和报告中，游戏显示名称去掉“审核映射”“暂定”等工作流标注；内部 `reviewed` 键不重命名。
- 所有 16 个自定义宗教图标编译为 256×256，按透明边界裁出有效画面后居中，最长边 240。
- 动态国旗按**本次**转换的国家、法律和源旗重新生成；仅附属关系变化不会把源旗缩到角落。政体变化的组合旗保留完整源图。不会加载旧战役的国名补丁。

这些设置保留历史证据的局限：模板姓名和外观不等于完成历史认证，未决核心本土继续留空，文化分组属于明确的游戏设计。不同源年份、地图和模组仍需对应规则支持。

## 0.12.1 显示与本土修复

旧的 `replace` 翻译文件可能覆盖新名称。升级会移除同一身份键的旧翻译，并验证中英文本唯一且符合当前规则。

满洲、京、乌兹别克、波兰恢复单一名称；同类的楚瓦什、罗马尼亚、卡努里、马拉地、缅甸、掸、马赞德兰、乔奎也恢复简洁名称。人口映射和各文化成员保持不变。京文化在有京文化居民的原版东京、安南、湄公河核心州补回本土。

`config/personal/religion_palette.json` 统一维护 16 个新增宗教的显示颜色。祆教火橙、苯教青蓝、耆那教金黄等仅为地图配色，不改变宗教归属和禁忌。

共享身份资源不再覆盖本战役的事件翻译；旧包从同一源战役的已校验政治导出补回缺失文本。导出验证现在覆盖自定义事件标题、正文、风味文本及选项。升级在独立目录完成，不重复经济补建，不重映射已转换人口，已保存编辑照常重放。静态验证不替代游戏内事件实测。

## 构建和更新

在旧通用规则基础上创建新目录，不覆盖输入：

```powershell
python -X utf8 tools/update_converter_identity_rules.py --root . --base <旧规则目录> --package <已验证的M5身份包> --out <新的规则目录> --game <V3游戏目录>
python -X utf8 tools/verify_converter_identity.py --rules <新的规则目录> --game <V3游戏目录> --eu5 <EU5游戏目录> --output <验证报告.json>
```

从头构建规则时，`build_converter_rules.py` 增加 `--identity-package` 与 `--game` 参数。身份资产包输入先校验输出哈希。构建后的身份资源不再依赖原始素材输入目录、M5 包或 `.local` 审核报告；完整转换仍需要受支持的游戏安装与基准存档。

旧本地调试构建的默认规则位于源码 `.local/converter/rules/` 和 `build/ConverterWorkbench/data/rules/`；发行版首次初始化会创建新规则目录并记住其路径。仅明确启用本地规则的代码刷新才同步旧默认规则；更新前保留原规则目录备份。每次转换仍复制独立规则快照，既有转换任务不被追溯改写。

## 验证

新增规则回读检查：所有映射目标、文化的宗教/传承/语言引用、传承与语言组引用、中英本地化、图标尺寸与中心、无战役历史泄漏、1337/1780/1836 三个年份的映射目标。

人口独立回读逐个源 POP 核对文化、宗教与完整分配；输出人口与居民账本及单列模板人口逐组比较；州历史国界与本次政治输出比较，移民本土重新核算全州占比。动态国旗检查附属与独立两种状态。游戏内显示与长期运行仍须新开局验证。

验证器覆盖规则引用和输出一致性。具体测试环境与公开验证范围见[验证记录](PUBLICATION.md)；完整规则与游戏衍生图标不随源码发布，资源准备条件见[发布流程](RELEASING.md)。
