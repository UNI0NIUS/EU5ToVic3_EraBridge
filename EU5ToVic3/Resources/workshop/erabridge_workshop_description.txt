[h1]EraBridge — EU5 → Victoria 3[/h1]

将 Europa Universalis V 战役转换为 Victoria 3 中文或英文模组，在下一时代继续游戏。
Convert a Europa Universalis V campaign into a Chinese- or English-language Victoria 3 mod.

[b]语言支持：工作台可即时切换简体中文或英文；导入和导出时独立选择游戏显示语言，并在 Victoria 3 中使用相同语言。[/b]
[b]Language support: switch the workbench between Simplified Chinese and English. Choose Game display language separately on import/export, and use the matching language in Victoria 3.[/b]

[b]v0.12.2-beta.3 Windows 社区测试版已发布 / Windows community test release available[/b]
本版提供可直接运行的 Windows x64 便携包，已附 Python 和运行依赖，无需另装开发工具。本工坊条目包含完整、已展开的转换器程序。订阅下载完成后，在 EU5 模组工具中打开本模组所在文件夹，双击根目录的 EU5Converter.exe 即可运行，无需解压。此程序独立运行，转换结果在 Victoria 3 中加载。
A runnable Windows x64 portable package is available, with Python and runtime dependencies included. No development tools are required. This Workshop item contains the complete extracted application. After the download finishes, open the mod folder from EU5 Mod Tools and run EU5Converter.exe at its root. No extraction is needed. The converter runs separately and produces mods for Victoria 3.

[h2]首次使用 / Getting started[/h2]
[list]
[*]订阅并等待下载完成，在 EU5 模组工具中打开本模组所在文件夹，双击 EU5Converter.exe，阅读并接受第三方组件条款。请保留完整目录，不要单独移动 EXE。
[*]点击“准备转换规则”，选择自己的 EU5、Victoria 3 游戏目录和 V3 原版 1836.1.1 开局存档。游戏与存档需自行提供。
[*]导入 EU5 存档，在工作台检查结果，调整人口、耕地或地区后导出所选语言的模组。在 Victoria 3 中选择对应语言，启用导出的模组，新开战役测试。
[*]Subscribe and wait for the download to finish. Open this mod folder from EU5 Mod Tools and run EU5Converter.exe, then read and accept the bundled third-party terms. Keep the complete application folder together.
[*]Use the rule preparation action to select your EU5 and Victoria 3 installations and a vanilla Victoria 3 save dated 1836.1.1. Provide your own games and save.
[*]Import an EU5 save, review and edit the conversion in the workbench, and export a mod in your selected language. Set Victoria 3 to the matching language, enable the exported mod, and start a new campaign.
[/list]

[h2]功能 / Features[/h2]
读取 EU5 存档，转换人口、国家、文化、宗教、政治关系、经济、军队和开局战争。桌面地图支持检查结果、调整人口与耕地、编辑归属与州界、保存项目和导出模组。
Import EU5 saves and convert populations, countries, cultures, religions, diplomacy, economy, armies, and opening wars. The desktop map workbench supports reviewing results, editing population, arable land, ownership and state borders, saving projects, and exporting mods.

[h2]版本与限制 / Versions and limitations[/h2]
主要验证环境为 Windows x64、EU5 1.3.11 和 Victoria 3 1.13.11。beta.3 新增中英切换、英文界面提示和独立的输出语言选择，并修复英文食物补建选项误用就业目标的问题。
The primary test environment is Windows x64, EU5 1.3.11 and Victoria 3 1.13.11. Beta.3 adds Chinese/English switching, English interface messages and independent output-language selection, and fixes the English food-construction option choosing the employment goal.

[b]已验证 / Verified[/b]
从 GitHub 重新下载的 beta.3 便携包已通过 SHA-256 核验。开发机上，一份 1337 年原版开局存档完成了规则初始化、完整转换、项目保存重开及中英文导出；3292 个地区回读一致，两种语言各通过 22748 个本地化键检查。两份导出的独立模组 ID 不同，其余 1056 个模组文件哈希一致。
A fresh download of the beta.3 portable package passed SHA-256 verification. On the developer machine, a vanilla 1337 starting save completed rule initialization, full conversion, project save/reopen and Chinese/English export. All 3,292 regions matched on readback, and each language passed checks for 22,748 localization keys. The exports have separate mod IDs; the remaining 1,056 mod files have identical hashes.

[b]已知存档兼容性问题 / Known save compatibility issue[/b]
抽样测试中的一份 1338 年 KNI 二进制存档在导入阶段报错“Unknown EU5 binary tokens”，未能完成转换。并非所有 EU5 存档都已兼容。遇到该错误时，请反馈游戏与存档版本、存档日期和导入日志；此问题尚未修复。
A sampled 1338 KNI binary save failed at import with “Unknown EU5 binary tokens” and could not be converted. Not all EU5 saves are compatible. If you encounter this error, report the game/save versions, save date and importer log. This issue remains unresolved.

上述检查属于开发机上的转换与静态回读，不等于游戏内验收。英文游戏内显示、独立 Windows 机器、其他游戏版本、第三方模组及长期战役仍待验证。此前 1337 样本中的资源建筑容量和部分原版脚本作用域报错仍是已知问题，可能导致资源建筑被引擎削减或动态州名等内容异常。食物、就业及财政指标包含静态估算。
These are developer-machine conversion and static readback checks, not in-game validation. English in-game display, independent Windows machines, other game versions, third-party mods and long campaigns remain unverified. Previously observed resource-building capacity and vanilla script-scope errors remain known issues; they may reduce resource buildings or affect features such as dynamic state names. Food, employment and fiscal indicators include static estimates.

转换器生成开局世界模组。在 Victoria 3 中选择对应语言、启用模组并新开战役，再由游戏保存为 .v3；转换器不直接生成 .v3 存档。
The converter produces a starting-world mod. Set Victoria 3 to the matching language, enable the mod and start a new campaign; Victoria 3 creates the .v3 save when you save that campaign.
